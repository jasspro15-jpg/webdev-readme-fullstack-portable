# Webdev Readme Fullstack Portable

A platform-neutral AI skill for using the `webdev-readme-fullstack` development guidance in different AI coding assistants and full-stack web projects.

## Install with npx

If your AI tool supports the `skills` installer:

```bash
npx skills add jasspro15-jpg/webdev-readme-fullstack-portable
```

Install globally for your user account:

```bash
npx skills add jasspro15-jpg/webdev-readme-fullstack-portable -g
```

Install only for the current project:

```bash
npx skills add jasspro15-jpg/webdev-readme-fullstack-portable -y
```

## Install manually

1. Download or clone this repository.
2. Copy `SKILL.md` into the AI tool's skills directory, or paste the Markdown body into that tool's project/system instructions.
3. Keep the filename `SKILL.md` and the skill folder name unchanged when the tool discovers skills by convention.

```bash
git clone https://github.com/jasspro15-jpg/webdev-readme-fullstack-portable.git
```

## What it covers

- React + TypeScript + Tailwind frontend conventions
- Express + tRPC typed backend workflow
- Drizzle schema and migration discipline
- Authentication and authorization boundaries
- Object storage guidance for large media
- Responsive, accessible UI standards
- Feature completion and verification checklist
- Adaptation guidance for non-Manus projects and AI tools without native skills

This is guidance for an AI coding agent; it does not install a runtime, database, credentials, or cloud services.
